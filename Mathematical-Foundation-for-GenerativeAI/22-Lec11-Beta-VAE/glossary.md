# Glossary: Mathematical Terminology for Lec 11 Beta- VAE

This glossary defines formal mathematical terms, phonetic pronunciations, software engineering analogies, theoretical invariants, and dedicated concept links for Lecture 11.

| Term | Spoken English (Phonetics) | Formal Definition | Plain-English Software Meaning | Mathematical Guarantee / Invariant | Dedicated MathsTerm Link |
|:---|:---|:---|:---|:---|:---|
| Beta-VAE | **BAY-tuh VEE AY EE** | $\mathcal{L}_\beta = \mathbb{E}_{q_\phi}[\log p_\theta(x\|z)] - \beta D_{KL}(q_\phi(z\|x) \parallel p(z))$ | A tunable autoencoder with a software dial (beta) that balances reconstruction sharpness against clean latent organization | Equivalent to standard VAE when $\beta = 1.0$; acts as a Lagrangian relaxation of constrained optimization | [Loss Functions](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/08-Loss_Functions.md) |
| Posterior Collapse | **pos-TEER-ee-er kuh-LAPS** | State where $q_\phi(z\|x) \to p(z)$ for all $x$, causing mutual information $I(X; Z) = 0$ | The encoder gets lazy and generates default random noise regardless of the input image, while decoder ignores the latent code | $D_{KL}(q_\phi(z\|x) \parallel p(z)) \to 0$ across all training samples | [Gradient Descent](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/09-Gradient_Descent.md) |
| Disentangled Representation | **dis-en-TANG-guld rep-ree-zen-TAY-shun** | Factorization $q(z\|x) = \prod_{k=1}^K q(z_k\|x)$ where each $z_k$ corresponds to an independent generative factor of variation | Separating independent concepts into dedicated dials: dial 1 controls object size, dial 2 controls rotation, dial 3 controls color | Zero total correlation $\text{TC}(Z) = D_{KL}(q(z) \parallel \prod_k q(z_k)) = 0$ | [Vectors and Matrices](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/01-Vectors_and_Matrices.md) |
| Lagrange Multiplier | **luh-GRAHNJ MUL-tih-ply-er** | Scalar $\lambda \ge 0$ used in the Lagrangian $\mathcal{L}(x, \lambda) = f(x) + \lambda(g(x) - c)$ for constrained optimization | A conversion exchange rate telling the optimizer how many units of error it can trade to satisfy a constraint | Optimal dual value enforces the KKT complementary slackness condition $\lambda^*(g(x^*) - c) = 0$ | [Functions and Derivatives](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/01-Functions_Derivatives_and_Rules.md) |
| Information Bottleneck | **in-for-MAY-shun BOT-ul-nek** | Principle minimizing $I(X; Z) - \beta I(Z; Y)$ to extract minimal sufficient statistics | A data compressor that throws away irrelevant background clutter while preserving vital object features | $I(X; Z) \le H(X)$ strictly bounded by the entropy of the source signal | [Common Probability Distributions](../../MathsTerms/03-Probability-and-Statistical-Estimation/02-Common_Probability_Distributions.md) |
| VampPrior | **VAMP PRY-er** | Prior $p(z) = \frac{1}{K} \sum_{k=1}^K q_\phi(z \| u_k)$ parameterized by learnable pseudo-inputs $u_k$ | A multimodal prior that learns multiple focal centers instead of forcing everything into one standard bell curve | Matches aggregate posterior directly: $p(z) \approx q(z)$, preventing over-regularization | [Common Probability Distributions](../../MathsTerms/03-Probability-and-Statistical-Estimation/02-Common_Probability_Distributions.md) |
| Dirac Delta Representation | **DEE-rak DEL-tuh rep-ree-zen-TAY-shun** | Distribution $\delta(z - z_0)$ with infinite density at $z_0$ and zero elsewhere | A hard deterministic lookup table where each input is assigned a single isolated memory address | Zero variance: $\sigma^2 = 0$; relative entropy to standard Gaussian prior approaches $+\infty$ | [Probability Basics and Axioms](../../MathsTerms/03-Probability-and-Statistical-Estimation/00-Probability_Basics_and_Axioms.md) |
| Mutual Information | **MYOO-choo-ul in-for-MAY-shun** | $I(X; Z) = D_{KL}(p(x, z) \parallel p(x)p(z))$ measuring shared statistical dependency | A metric measuring how many bits of information knowing the latent code $z$ gives you about original image $x$ | Non-negative: $I(X; Z) \ge 0$; equals 0 if and only if $X$ and $Z$ are statistically independent | [Loss Functions](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/08-Loss_Functions.md) |
