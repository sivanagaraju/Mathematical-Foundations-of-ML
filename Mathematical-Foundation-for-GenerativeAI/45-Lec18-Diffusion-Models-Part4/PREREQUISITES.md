## Foundational Pillar 1: Tweedie's Formula in Classical Gaussian Denoising

### Mathematical Derivation & Concept
In 1956, statistician Maurice Tweedie established a remarkable identity in empirical Bayes analysis. Consider an unknown signal $x_0 \sim p(x_0)$ contaminated by additive Gaussian noise:
$$x_t \sim \mathcal{N}(x_t; x_0, \sigma_t^2 I)$$
The marginal distribution of the noisy observation is:
$$p(x_t) = \int p(x_0) \mathcal{N}(x_t; x_0, \sigma_t^2 I) dx_0$$

Tweedie proved that the posterior expectation of the true clean signal $x_0$ conditioned on observing noisy state $x_t$ can be calculated without knowing the prior distribution $p(x_0)$, using solely the gradient of the marginal distribution:
$$\mathbb{E}[x_0 \mid x_t] = x_t + \sigma_t^2 \nabla_{x_t} \log p(x_t)$$

This theorem shows that denoising is fundamentally equivalent to computing the score function $\nabla_{x_t} \log p(x_t)$!

```
                  TWEEDIE'S GEOMETRIC VECTOR ADDITION
                  
   Observed Noisy Vector x_t --------------------------+
                                                       |
   Score Vector:  + sigma_t^2 * nabla_{x_t} log p(x_t) |  (Points uphill toward manifold)
                                                       v
   Recovered Clean Centroid:  E[ x_0 | x_t ] <---------+
```

### Micro-Number Numerical Verification
Let $x_t = 3.0$, $\sigma_t^2 = 0.5$, and suppose the score gradient is $\nabla_{x_t} \log p(x_t) = -2.0$.
$$\mathbb{E}[x_0 \mid x_t] = 3.0 + 0.5 \times (-2.0) = 3.0 - 1.0 = 2.0$$
The score vector correctly pulls the noisy point back toward the true data mean at $2.0$.

### Physical Analogy
Imagine a lost hiker wandering in thick fog on a hill ($x_t$). If the hiker can feel the slope of the hill under their boots ($\nabla \log p(x_t)$), they don't need a satellite map of the entire continent; they simply walk uphill along the gradient to find the village shelter ($\mathbb{E}[x_0 \mid x_t]$).

### Runnable Python Verification
```python
import torch

def verify_tweedie():
    # 1D Gaussian prior p(x0) = N(0, 1)
    # Contaminated with noise N(0, sigma^2) -> marginal p(xt) = N(0, 1 + sigma^2)
    sigma_sq = 0.25
    xt = torch.tensor([1.5], requires_grad=True)
    
    # Analytical marginal log p(xt) = -0.5 * xt^2 / (1 + sigma_sq) - const
    log_p = -0.5 * (xt**2) / (1.0 + sigma_sq)
    log_p.backward()
    score = xt.grad.item()
    
    # Tweedie estimate
    tweedie_est = xt.item() + sigma_sq * score
    
    # Analytical Bayes posterior mean for Gaussian: (1 / (1 + sigma^2)) * xt
    bayes_mean = (1.0 / (1.0 + sigma_sq)) * xt.item()
    
    assert abs(tweedie_est - bayes_mean) < 1e-5
    print(f"Tweedie verified: est={tweedie_est:.4f}, bayes={bayes_mean:.4f}")

verify_tweedie()
```

## Foundational Pillar 2: Score Matching Connection to Noise Prediction

### Mathematical Derivation & Concept
Recall from DDPM that our forward jump kernel is:
$$x_t = \sqrt{\bar{\alpha}_t} x_0 + \sqrt{1 - \bar{\alpha}_t} \epsilon, \quad \epsilon \sim \mathcal{N}(0, I)$$
Dividing by $\sqrt{\bar{\alpha}_t}$, this is equivalent to $x_t' = x_0 + \sigma_t \epsilon$, where $\sigma_t = \frac{\sqrt{1 - \bar{\alpha}_t}}{\sqrt{\bar{\alpha}_t}}$.
Applying Tweedie's formula directly to this perturbation yields:
$$\nabla_{x_t} \log q(x_t \mid x_0) = -\frac{\epsilon}{\sqrt{1 - \bar{\alpha}_t}}$$

When we train a neural network $\epsilon_\theta(x_t, t)$ to predict $\epsilon$, the network is implicitly learning the score function of the perturbed data distribution:
$$s_\theta(x_t, t) \equiv \nabla_{x_t} \log p(x_t) = -\frac{\epsilon_\theta(x_t, t)}{\sqrt{1 - \bar{\alpha}_t}}$$

Thus, DDPM noise prediction and Song & Ermon's Denoising Score Matching are mathematically identical parameterizations of the exact same continuous vector field!

### Micro-Number Numerical Verification
Let $\sqrt{1 - \bar{\alpha}_t} = 0.5$. If injected noise $\epsilon = 1.2$, the true local score vector is:
$$\nabla_{x_t} \log q(x_t \mid x_0) = -\frac{1.2}{0.5} = -2.4$$

### Physical Analogy
A weather map showing atmospheric pressure. The predicted noise is the barometric wind velocity vector; following the negative noise vector moves you directly into high-pressure centers of data probability.

### Runnable Python Verification
```python
import torch

def verify_score_noise_relation():
    eps = torch.tensor([1.2])
    std = torch.tensor([0.5])
    score = -eps / std
    assert score.item() == -2.4
    print(f"Score-noise relationship verified: score={score.item():.4f}")

verify_score_noise_relation()
```

## Foundational Pillar 3: Perceptual Compression in Latent Diffusion Models (LDM)

### Mathematical Derivation & Concept
Pixel-space diffusion suffers from immense computational overhead: running 1,000 steps of a 2D U-Net on $512 \times 512 \times 3$ images requires computing attention on $(512/8)^2 = 4096$ tokens across hundreds of millions of parameters.
Rombach et al. (2022) observed that digital images contain two distinct forms of complexity:
1. **Perceptual Complexity**: High-frequency, imperceptible pixel correlations (sub-pixel noise, sensor artifacts).
2. **Semantic Complexity**: High-level semantic relationships (identifying objects, poses, background context).

Latent Diffusion Models decouple these two regimes:
- A pretrained autoencoder (VQ-GAN / KL-VAE) compresses high-dimensional pixel space $\mathbb{R}^{3 \times 512 \times 512}$ down to a lower-dimensional latent space $z_0 \in \mathbb{R}^{4 \times 64 \times 64}$ (a $64\times$ reduction in spatial memory).
- The diffusion process operates strictly on latent vectors $z_t \in \mathbb{R}^{4 \times 64 \times 64}$.
- At test time, reverse diffusion synthesizes clean latent $z_0$, which is passed through decoder $\mathcal{D}(z_0)$ to render the high-resolution image.

```
   Pixel Space:    x_0 (3 x 512 x 512) -----------------------------------> Reconstructed x_0
                          |                                                       ^
                    [ Encoder E ]                                           [ Decoder D ]
                          v                                                       |
   Latent Space:   z_0 (4 x 64 x 64) ===(Diffusion Forward / Reverse)===> Latent z_0
```

### Micro-Number Numerical Verification
Input dimensions: $3 \times 512 \times 512 = 786,432$ values.
Latent dimensions: $4 \times 64 \times 64 = 16,384$ values.
Compression ratio: $\frac{786,432}{16,384} = 48.0\times$ fewer parameters to process per U-Net attention pass!

### Physical Analogy
Writing a musical score. Rather than recording every raw acoustic air pressure wave (gigabytes of sound data), the composer writes compact musical notes on staff paper ($z_0$). The orchestra (decoder $\mathcal{D}$) reads the notes and performs the rich acoustic symphony.

### Runnable Python Verification
```python
import torch

def verify_latent_compression():
    pixel_dim = 3 * 512 * 512
    latent_dim = 4 * 64 * 64
    ratio = pixel_dim / latent_dim
    assert ratio == 48.0
    print(f"Latent compression ratio verified: {ratio:.1f}x reduction")

verify_latent_compression()
```

## Foundational Pillar 4: Continuous-Time Stochastic Differential Equations (SDEs)

### Mathematical Derivation & Concept
As the number of discrete diffusion steps $T \to \infty$ and step size $\Delta t \to 0$, the forward process converges to an Itô Stochastic Differential Equation (SDE):
$$dx = f(x, t) dt + g(t) d\mathbf{w}$$
where $f(x, t)$ is the drift coefficient, $g(t)$ is the diffusion coefficient, and $\mathbf{w}$ is standard Brownian motion.

- **Variance Preserving (VP) SDE (corresponds to DDPM)**:
  $$dx = -\frac{1}{2} \beta(t) x dt + \sqrt{\beta(t)} d\mathbf{w}$$
- **Variance Exploding (VE) SDE (corresponds to SGM)**:
  $$dx = \sqrt{\frac{d[\sigma^2(t)]}{dt}} d\mathbf{w}$$

By Anderson's theorem (1982), every forward SDE has an exact **reverse-time SDE**:
$$dx = \left[ f(x, t) - g(t)^2 \nabla_x \log p_t(x) \right] dt + g(t) d\bar{\mathbf{w}}$$
where $d\bar{\mathbf{w}}$ is Brownian motion running backward in time.
By estimating $\nabla_x \log p_t(x)$ via neural network $s_\theta(x, t)$, we can integrate this equation backward using standard numerical differential equation solvers (Euler-Maruyama, Runge-Kutta).

### Micro-Number Numerical Verification
In VP SDE, drift is $-\frac{1}{2}\beta(t)x$. If $\beta(t) = 0.2$ and $x = 4.0$:
$$\text{Drift} = -0.5 \times 0.2 \times 4.0 = -0.4$$
The state contracts smoothly toward zero while noise is added.

### Physical Analogy
Langevin dynamics describing pollen grains suspended in water. The pollen drifts toward equilibrium while buffeted by water molecules. Reversing time requires subtracting the molecular drag force and applying reverse Brownian motion.

### Runnable Python Verification
```python
import torch

def verify_sde_drift():
    beta_t = 0.2
    x = torch.tensor([4.0])
    drift = -0.5 * beta_t * x
    assert abs(drift.item() - (-0.4)) < 1e-5
    print(f"VP SDE drift verified: {drift.item():.4f}")

verify_sde_drift()
```

## Diagnostics Self-Assessment

1. **How does Tweedie's formula allow us to reconstruct $\mathbb{E}[x_0 \mid x_t]$ from a score network?**  
   *Answer*: Tweedie's formula dictates $\mathbb{E}[x_0 \mid x_t] = x_t + \sigma_t^2 \nabla_{x_t} \log p(x_t)$. Substituting $s_\theta(x_t) = -\frac{\epsilon_\theta}{\sigma_t}$ recovers the clean estimate directly: $\hat{x}_0 = x_t - \sigma_t \epsilon_\theta$.

2. **Why does Latent Diffusion Model (LDM) achieve identical or superior visual quality to pixel diffusion with $50\times$ less compute?**  
   *Answer*: Because high-frequency sub-pixel noise is absorbed by the VAE autoencoder's perceptual loss, leaving the diffusion U-Net free to focus purely on semantic composition and spatial geometry in compressed latent space.
