# Glossary: Mathematical Terminology for Tutorial 16 VQ-VAE Implementation

This glossary defines formal mathematical terms, phonetic pronunciations, software engineering analogies, theoretical invariants, and dedicated concept links for Tutorial 16.

| Term | Spoken English (Phonetics) | Formal Definition | Plain-English Software Meaning | Mathematical Guarantee / Invariant | Dedicated MathsTerm Link |
|:---|:---|:---|:---|:---|:---|
| Codebook Embedding | **KOHD-buuk em-BED-ing** | $\mathcal{E} \in \mathbb{R}^{K \times D}$ represented as `nn.Embedding(K, D)` | A lookup table containing $K$ standard prototype feature vectors of length $D$ | Finite discrete capacity: exactly $\log_2 K$ bits of information per spatial token | [Encodings Categorical & Embeddings](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/08-Encodings_Categorical_and_Embeddings.md) |
| Straight-Through Detach Trick | **STRAYT THROO dee-TACH TRIK** | $z_q = z_e + (z_q - z_e).\text{detach}()$ | A single-line PyTorch programming trick that outputs discrete tokens forward while copying gradients backward | Derivative invariant: $\frac{\partial z_q}{\partial z_e} = \mathbf{I}$ on backward pass | [Chain Rule & Backpropagation](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/04-Chain_Rule_and_Backpropagation.md) |
| Vectorized Distance Expansion | **VEK-ter-ized DIS-tens ek-SPAN-shun** | $\|z - e\|^2 = \|z\|^2 + \|e\|^2 - 2 z e^T$ | Rewriting Euclidean distance as matrix multiplications to run thousands of times faster on GPU tensor cores | Exact equivalence to squared Euclidean distance: $\|z - e\|_2^2 \ge 0$ | [Dot Product & Similarity](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/03-Dot_Product_and_Similarity.md) |
| Codebook Perplexity | **KOHD-buuk per-PLEK-sih-tee** | $\exp(H) = \exp\left( -\sum_{k=1}^K p_k \log p_k \right)$ | A metric measuring how many distinct dictionary words the network is actively using out of $K$ available words | Bounded range: $1.0 \le \text{Perplexity} \le K$; equals $K$ under perfectly uniform usage | [Entropy & Cross-Entropy](../../MathsTerms/04-Information-Theory-and-Divergences/01-Entropy_CrossEntropy_CCE.md) |
| VQ Codebook Loss | **VEE-KYOO KOHD-buuk LOSS** | $\mathcal{L}_{vq} = \|\text{sg}[z_e] - z_q\|_2^2$ | The objective term that pulls the chosen codebook vector toward the encoder's continuous thoughts | Updates dictionary exclusively: $\nabla_{z_e} \mathcal{L}_{vq} = \mathbf{0}$ via `.detach()` | [Loss Functions](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/08-Loss_Functions.md) |
| Commitment Loss | **kuh-MIT-ment LOSS** | $\mathcal{L}_{commit} = \beta \|z_e - \text{sg}[z_q]\|_2^2$ | An elastic tether penalizing the encoder if its outputs drift away from the dictionary centroids | Updates encoder exclusively: $\nabla_{z_q} \mathcal{L}_{commit} = \mathbf{0}$ via `.detach()` | [Loss Functions](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/08-Loss_Functions.md) |
| Nearest Neighbor Argmin | **NEER-est NAY-ber AHRG-min** | $k^* = \arg\min_{k} \|z_e - e_k\|_2^2$ | Finding which row in the dictionary table has the smallest physical distance to the encoder's vector | Partitions the continuous space into $K$ non-overlapping Voronoi cells | [Argmax](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/07-Argmax.md) |
| Permute and Contiguous | **per-MYOOT and kon-TIG-yoo-us** | `x.permute(0, 2, 3, 1).contiguous()` | Re-ordering tensor dimensions from Channel-First to Channel-Last and reorganizing memory for safe reshaping | Ensures underlying RAM layout matches indexing strides before calling `.view()` | [Tensors & Shapes](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/04-Tensors_and_Shapes.md) |
