# Glossary: Mathematical Terminology for Tutorial 13 WGAN Weight Clipping

This glossary defines formal mathematical terms, phonetic pronunciations, software engineering analogies, theoretical invariants, and dedicated concept links for Tutorial 13.

| Term | Spoken English (Phonetics) | Formal Definition | Plain-English Software Meaning | Mathematical Guarantee / Invariant | Dedicated MathsTerm Link |
|:---|:---|:---|:---|:---|:---|
| Wasserstein Distance | **VAH-ser-shtyn DIS-tens** | $W_1(P_r, P_g) = \inf_{\gamma \in \Pi} \mathbb{E}_{(x, y) \sim \gamma}[\|x - y\|]$ | The minimum total work (mass times distance) needed to shovel one pile of data into the shape of another | Continuous and differentiable almost everywhere, even when probability supports are completely disjoint | [Wasserstein Distance & EMD](../../MathsTerms/05-Information-Theory-and-Divergences/05-Wasserstein_Distance_and_EMD.md) |
| Kantorovich-Rubinstein Duality | **kan-tor-OH-vitch ROO-bin-steen doo-AL-ih-tee** | $W_1(P_r, P_g) = \sup_{\|f\|_L \le 1} \mathbb{E}_{P_r}[f(x)] - \mathbb{E}_{P_g}[f(x)]$ | Converts an impossible search over all moving plans into training a single well-behaved scoring neural network | Transforms an intractable infimum over couplings into a tractable supremum over 1-Lipschitz functions | [Fenchel Conjugate & Dual Representations](../../MathsTerms/01-Primal-Analysis-and-Foundations/05-Fenchel_Conjugate_and_Dual_Representations.md) |
| Lipschitz Continuity | **LIP-shits kon-tih-NYOO-ih-tee** | $|f(x_1) - f(x_2)| \le K \|x_1 - x_2\|$ | A strict speed limit on the function: it can never change faster than $K$ times the input distance | Bounded gradient: $\|\nabla_x f(x)\|_2 \le K$ almost everywhere | [Lipschitz Continuity](../../MathsTerms/01-Primal-Analysis-and-Foundations/04-Lipschitz_Continuity.md) |
| Critic Network | **KRIT-ik NET-werk** | A neural network $f_w: \mathbb{R}^D \to \mathbb{R}$ approximating the dual witness function | A judge that outputs a continuous real score telling the generator how much work remains to match real data | Has no final Sigmoid activation; outputs unbounded real values in $(-\infty, +\infty)$ | [Loss Functions](../../MathsTerms/03-Multivariate-Calculus-and-Optimization/08-Loss_Functions.md) |
| Weight Clipping | **WAYT KLIP-ing** | $w \leftarrow \text{clamp}(w, -c, c)$ | A blunt software guardrail clamping network weights into a small numeric box after every step | Guarantees the network is $K$-Lipschitz, but causes weights to saturate at extreme boundaries | [Gradient Descent](../../MathsTerms/03-Multivariate-Calculus-and-Optimization/09-Gradient_Descent.md) |
| Earth Mover's Distance | **ERTH MOO-verz DIS-tens** | Equivalent formulation of 1-Wasserstein distance | Measuring how many tons of dirt you must move, multiplied by how many miles you must carry it | Metric property: $W_1(P_r, P_g) \ge 0$, equals 0 if and only if $P_r \equiv P_g$ | [Wasserstein Distance & EMD](../../MathsTerms/05-Information-Theory-and-Divergences/05-Wasserstein_Distance_and_EMD.md) |
| Critic Steps | **KRIT-ik STEPS** | Running the Critic for $n_{critic} = 5$ iterations per generator step | Giving the judge extra practice rounds so its scoring accurately reflects true transport distance | Ensures the Critic remains close to the supremum required by Kantorovich duality | [Gradient Descent](../../MathsTerms/03-Multivariate-Calculus-and-Optimization/09-Gradient_Descent.md) |
| RMSprop Optimizer | **AHR EM ESS PROP OP-tih-my-zer** | $w_{t+1} = w_t - \frac{\eta}{\sqrt{v_t} + \epsilon} g_t$ without momentum | An adaptive learning rate optimizer that adjusts step size without carrying heavy directional momentum | Prevents unstable oscillations when weights hit hard clipping boundaries | [Gradient Descent](../../MathsTerms/03-Multivariate-Calculus-and-Optimization/09-Gradient_Descent.md) |
