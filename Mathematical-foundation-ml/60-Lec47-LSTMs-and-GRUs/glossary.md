# Mathematical Glossary — Lecture 47: LSTMs and GRUs

This glossary provides exact spoken English pronunciations, formal mathematical definitions, operational systems roles, and disk-verified cross-references for core terminology introduced in Lecture 47.

| Term | Spoken English (Phonetic Syllables) | Concept Anchor | Formal Mathematical Definition | Operational Role in Deep Systems | Reference Dossier |
|:-----|:-----------------------------------|:---------------|:-------------------------------|:---------------------------------|:------------------|
| **Additive Gradient Highway** | *AD-ih-tiv GRAY-dee-unt HYE-way* | Gradient Preservation | Recurrent state transition $h_t = \alpha_t \odot h_{t-1} + F(x_t, h_{t-1})$ yielding Jacobian $\frac{\partial h_t}{\partial h_{t-1}} = \operatorname{diag}(\alpha_t) + \frac{\partial F}{\partial h_{t-1}}$ | Provides an unattenuated identity pathway across time, eliminating multiplicative vanishing gradients | [Chain Rule & Backprop](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/04-Chain_Rule_and_Backpropagation.md) |
| **Cell State ($c_t$)** | *SEE TEE* | Internal Memory Linear Carousel | $c_t = f_t \odot c_{t-1} + i_t \odot \tilde{c}_t$, where $c_t \in \mathbb{R}^m$ | Serves as the dedicated, uncompressed linear memory conveyor belt of an LSTM cell | [Recurrent Neural Networks](../../MathsTerms/06-Deep-Architectures-and-Generative-Models/02-Recurrent_Neural_Networks.md) |
| **Forget Gate ($f_t$ / $\alpha_t$)** | *FOR-get GAYT / AL-fuh TEE* | Information Retention Modulator | $f_t = \sigma(W_f x_t + U_f h_{t-1} + b_f) \in [0, 1]^m$ | Dynamically scales previous memory coordinate-by-coordinate; initialized to $+1.0$ for open transmission | [Activation Functions](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/05-Activation_Functions.md) |
| **Input Gate ($i_t$ / $\beta_t$)** | *IN-put GAYT / BAY-tuh TEE* | Candidate Write Modulator | $i_t = \sigma(W_i x_t + U_i h_{t-1} + b_i) \in [0, 1]^m$ | Controls which coordinates of the candidate vector $\tilde{c}_t$ are written into the cell state | [Activation Functions](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/05-Activation_Functions.md) |
| **Output Gate ($o_t$)** | *OUT-put GAYT* | Latent State Readout Modulator | $o_t = \sigma(W_o x_t + U_o h_{t-1} + b_o) \in [0, 1]^m$ | Filters cell state through non-linear squashing to produce observable state $h_t = o_t \odot \tanh(c_t)$ | [Activation Functions](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/05-Activation_Functions.md) |
| **Candidate State ($\tilde{h}_t$)** | *AYCH TIL-duh TEE* | Feature Transformation Branch | $\tilde{h}_t = \tanh(W_c x_t + U_c h_{t-1} + b_c) \in [-1, 1]^m$ | Computes raw proposed non-linear state updates combining new observations and historical context | [Activation Functions](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/05-Activation_Functions.md) |
| **Update Gate ($z_t$)** | *UP-dayt GAYT / ZEE TEE* | Convex Interpolation Modulator | $z_t = \sigma(W_z x_t + U_z h_{t-1} + b_z) \in [0, 1]^m$ | Governs the balance between past memory retention and candidate injection in GRU: $h_t = (1-z_t)h_{t-1} + z_t \tilde{h}_t$ | [Activation Functions](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/05-Activation_Functions.md) |
| **Reset Gate ($r_t$)** | *REE-set GAYT / AR TEE* | Past Memory Ignorer | $r_t = \sigma(W_r x_t + U_r h_{t-1} + b_r) \in [0, 1]^m$ | Modulates how much previous state $h_{t-1}$ influences candidate generation: $\tilde{h}_t = \tanh(W x_t + U (r_t \odot h_{t-1}))$ | [Activation Functions](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/05-Activation_Functions.md) |
| **Highway Network** | *HYE-way NET-wurk* | Feedforward Additive Architecture | $y = T(x) \odot H(x) + (1 - T(x)) \odot x$ where $T(x) = \sigma(W_T x + b_T)$ | First feedforward architecture to train hundreds of layers by providing an unattenuated identity shortcut | [Linear Maps](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/01-Vectors_and_Matrices.md) |
| **Residual Skip Connection** | *reh-ZID-yoo-ul SKIP kuh-NEK-shun* | Spatial Identity Shortcut | $y = x + F(x)$ across layer depth $l$ | Ensures single-layer Jacobian is $\mathbf{I} + \frac{\partial F}{\partial x}$, preserving gradients across hundreds of layers | [Linear Maps](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/01-Vectors_and_Matrices.md) |
