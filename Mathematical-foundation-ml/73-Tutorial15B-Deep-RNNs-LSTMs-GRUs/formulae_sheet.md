# Formulae Sheet & Rapid Revision — Tutorial 15 Part 2: Deep RNNs, LSTMs and GRUs

This sheet consolidates all mathematical formulations, vertical layer equations, tensor dimensions, parameter counting derivations, and architectural invariants for **Tutorial 15 Part 2: Deep Recurrent Neural Networks, LSTMs, GRUs, and Sequence Modeling Mechanics**.

---

## 1. Input & State Tensor Dimensions

| Tensor Variable | Mathematical Domain | PyTorch Layout (`batch_first=True`) | Architectural Description |
|:----------------|:--------------------|:-----------------------------------|:--------------------------|
| $\mathbf{X}$ | $\mathbb{R}^{B \times T \times D}$ | `[B, T, D]` | Mini-batch input sequence tensor |
| $h_t^{(l)}$ | $\mathbb{R}^H$ | `[B, H]` | Hidden state vector at vertical layer $l$ and time step $t$ |
| $C_t^{(l)}$ | $\mathbb{R}^H$ | `[B, H]` | Cell state vector at vertical layer $l$ and time step $t$ |
| $\text{output}$ | $\mathbb{R}^{B \times T \times (D_{\text{dir}} \cdot H)}$ | `[B, T, D_dir * H]` | Hidden activations of top layer $L$ across all sequence steps $T$ |
| $\mathbf{h}_n$ | $\mathbb{R}^{(L \cdot D_{\text{dir}}) \times B \times H}$ | `[L * D_dir, B, H]` | Terminal hidden state at time $T$ across all vertical layers |
| $\mathbf{c}_n$ | $\mathbb{R}^{(L \cdot D_{\text{dir}}) \times B \times H}$ | `[L * D_dir, B, H]` | Terminal cell state at time $T$ across all vertical layers (LSTM) |
| $\mathbf{z}_{\text{cls}}$ (Many-to-One) | $\mathbb{R}^{B \times K}$ | `[B, K]` | Logits from linear projection head $W_y h_T^{(L)} + b_y$ |
| $\mathbf{Z}_{\text{seq}}$ (Many-to-Many) | $\mathbb{R}^{B \times T \times K}$ | `[B, T, K]` | Logits from dense token projection head $W_y \text{output} + b_y$ |

## 2. Deep Stacked Recurrence Equations

For vertical depth $L \ge 2$:
1. **Layer 1 ($l=1$):**
   $$h_t^{(1)} = \sigma_{\text{cell}}\left( W_{ih}^{(1)} x_t + W_{hh}^{(1)} h_{t-1}^{(1)} + b_{ih}^{(1)} + b_{hh}^{(1)} \right)$$
2. **Intermediate and Top Layers ($l \in \{2, \dots, L\}$):**
   $$h_t^{(l)} = \sigma_{\text{cell}}\left( W_{ih}^{(l)} h_t^{(l-1)} + W_{hh}^{(l)} h_{t-1}^{(l)} + b_{ih}^{(l)} + b_{hh}^{(l)} \right)$$
   where $W_{ih}^{(1)} \in \mathbb{R}^{M \cdot H \times D}$ and $W_{ih}^{(l)} \in \mathbb{R}^{M \cdot H \times H}$ for $l \ge 2$, with multiplier $M \in \{1 \text{ (RNN)}, 3 \text{ (GRU)}, 4 \text{ (LSTM)}\}$.

---

## 3. Bidirectional Recurrence Formulations

For bidirectional recurrence ($D_{\text{dir}} = 2$):
1. **Forward Sweep ($t = 1 \to T$):**
   $$h_t^\to = \sigma_{\text{cell}}\left( W_{ih}^\to x_t + W_{hh}^\to h_{t-1}^\to + b^\to \right)$$
2. **Backward Sweep ($t = T \to 1$):**
   $$h_t^\leftarrow = \sigma_{\text{cell}}\left( W_{ih}^\leftarrow x_t + W_{hh}^\leftarrow h_{t+1}^\leftarrow + b^\leftarrow \right)$$
3. **Concatenation Fusion:**
   $$h_t = \left[ h_t^\to ; h_t^\leftarrow \right] \in \mathbb{R}^{2H}$$
4. **Terminal Representation Slicing:**
   $$h_{\text{fused}, T} = \left[ \mathbf{h}_n[-2] ; \mathbf{h}_n[-1] \right] = \left[ \text{output}[:, -1, :H] ; \text{output}[:, 0, H:] \right] \in \mathbb{R}^{B \times 2H}$$

## 4. Multi-Layer & Bidirectional Parameter Counting Formulas

Let $M \in \{1 \text{ (RNN)}, 3 \text{ (GRU)}, 4 \text{ (LSTM)}\}$:
- **Layer 1 Parameters:**
  $$P_1 = D_{\text{dir}} \cdot M \cdot \left[ H \cdot D + H \cdot H + 2H \right]$$
- **Subsequent Layers ($l \in \{2, \dots, L\}$):**
  - If previous layer is unidirectional: input is $H$, so $P_l = D_{\text{dir}} \cdot M \cdot [H \cdot H + H \cdot H + 2H]$.
  - If previous layer is bidirectional: input is $2H$, so $P_l = D_{\text{dir}} \cdot M \cdot [H \cdot 2H + H \cdot H + 2H]$.
- **Total Recurrent Parameters:**
  $$P_{\text{total}} = P_1 + \sum_{l=2}^L P_l$$

### Worked Example:
- Config: $D=10, H=16, L=2$, Unidirectional, Dual-Bias:
  - Layer 1 RNN: $1 \cdot [16 \cdot 10 + 16 \cdot 16 + 32] = 160 + 256 + 32 = 448$.
  - Layer 2 RNN: $1 \cdot [16 \cdot 16 + 16 \cdot 16 + 32] = 256 + 256 + 32 = 544$.
  - Total RNN: $448 + 544 = 992$.
  - Total GRU ($M=3$): $3 \times 992 = 2,976$.
  - Total LSTM ($M=4$): $4 \times 992 = 3,968$.

## 5. Guarantees & Invariants

1. **Top-Layer Sequence Invariant:** In PyTorch, `output` is strictly and exclusively generated by the top-most layer $L$ across all time steps $T$. Intermediate layers $1 \dots L-1$ are not represented in `output`.
2. **Terminal Layer Invariant:** The tensor `h_n` always contains exactly $L \cdot D_{\text{dir}}$ slices along dimension 0, capturing the terminal hidden state $h_T^{(l)}$ of every layer.
3. **Top-Layer Terminal Equivalence Invariant:** For any unidirectional model, the final time-slice of the sequence output matches the top-layer terminal hidden state identically:
   $$\text{output}[:, -1, :] \equiv \mathbf{h}_n[-1, :, :]$$
4. **Directional Interleaving Invariant:** In bidirectional PyTorch layers, even indices $2l$ of `h_n` represent the forward direction, and odd indices $2l+1$ represent the backward direction for layer $l$.

## 6. Contrastive Decision Table

| Architectural Choice | Primary Use Case | Output Tensor Shape | Latency Characteristics | Hardware Suitability |
|:---|:---|:---|:---|:---|
| **Single-Layer Unidirectional** | Real-time streaming edge sensors | `output`: `[B, T, H]` | Lowest sequential latency | Microcontrollers, mobile devices |
| **Deep Stacked Unidirectional** | Complex multi-tier time series | `output`: `[B, T, H_L]` | Moderate latency ($O(L \cdot T)$) | Cloud servers, sequential inference |
| **Bidirectional LSTM (BiLSTM)** | Offline text encoding, NER, tagging | `output`: `[B, T, 2H]` | $2\times$ compute per step | High-throughput offline batching |
| **Self-Attention (Transformer)** | High-throughput generative NLP, LLMs | `output`: `[B, T, D]` | Minimal wall-clock latency ($O(1)$) | Modern massive GPU tensor cores |

## 7. Numerical Stability & Traps

1. **Shallow State Slicing Bug:** Slicing `h_n[0]` in a multi-layer stack accesses Layer 1 instead of Layer $L$. Always index with `h_n[-1]`.
2. **Bidirectional Temporal Inversion:** Slicing `output[:, -1, :]` in a bidirectional model couples the final forward state with the *first* backward step. Always slice `h_n[-2]` and `h_n[-1]`.
3. **Gradient Exploding across Deep Stacks:** Increasing $L$ and $T$ increases the maximum backpropagation path length to $O(L + T)$. Always apply `torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)` to bound gradient steps.
4. **Batch Layout Omission:** Passing `[B, T, D]` without `batch_first=True` causes PyTorch to interpret batch size as sequence length, silently scrambling inputs without throwing an error when $B=T$.
