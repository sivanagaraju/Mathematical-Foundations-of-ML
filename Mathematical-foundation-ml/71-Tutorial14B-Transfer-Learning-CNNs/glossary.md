### Transfer Learning
- **Spoken / Phonetic:** /ˈtræns.fɜːr ˈlɜː.nɪŋ/ (TRANS-fur LER-ning)
- **Formal Definition:** A machine learning paradigm where knowledge acquired from training a model $\mathcal{M}$ on a source domain $\mathcal{D}_S$ and task $\mathcal{T}_S$ is transferred to improve learning on a target domain $\mathcal{D}_T$ and task $\mathcal{T}_T$.
- **Intuitive Explanation:** Taking a network that already knows how to see (trained on millions of internet photos) and re-purposing it for a new specialized task (like spotting tumors in X-rays).
- **Reference Term:** [01-Convolution_and_Pooling.md](../../MathsTerms/06-Deep-Architectures-and-Generative-Models/01-Convolution_and_Pooling.md)

---

### Parameter Freezing
- **Spoken / Phonetic:** /pəˈræm.ɪ.tər ˈfriː.zɪŋ/ (puh-RAM-ih-ter FREE-zing)
- **Formal Definition:** The operational constraint enforcing $\frac{\partial \mathcal{L}}{\partial \theta_j} = \emptyset$ by setting `param.requires_grad = False`, preventing gradient computation and parameter updates for specified layers during automatic differentiation.
- **Intuitive Explanation:** Locking the dials of the feature extraction machine so that training only adjusts the final output pointer without disturbing existing skills.
- **Reference Term:** [04-Chain_Rule_and_Backpropagation.md](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/04-Chain_Rule_and_Backpropagation.md)

---

### Residual Connection (Skip Connection)
- **Spoken / Phonetic:** /rɪˈzɪd.ju.əl kəˈnɛk.ʃən/ (reh-ZID-yoo-ul kuh-NEK-shun)
- **Formal Definition:** An architectural shortcut that reformulates layered transformations as learning a residual mapping $\mathcal{F}(\mathbf{x}) := \mathcal{H}(\mathbf{x}) - \mathbf{x}$, computing $\mathbf{y} = \mathcal{F}(\mathbf{x}) + \mathbf{x}$.
- **Intuitive Explanation:** Adding an express elevator that passes original signals straight through to future layers, guaranteeing that gradients never vanish.
- **Reference Term:** [01-Convolution_and_Pooling.md](../../MathsTerms/06-Deep-Architectures-and-Generative-Models/01-Convolution_and_Pooling.md)

---

### Latent Embedding Vector
- **Spoken / Phonetic:** /ˈleɪ.tənt ɛmˈbɛd.ɪŋ/ (LAY-tunt em-BED-ing)
- **Formal Definition:** A dense, continuous vector representation $\mathbf{z} \in \mathbb{R}^D$ extracted from an intermediate layer of a neural network, encoding high-level semantic attributes in a low-dimensional manifold.
- **Intuitive Explanation:** A compact numerical fingerprint summarizing the visual meaning of an image.
- **Reference Term:** [03-Autoencoders_and_Latent_Spaces.md](../../MathsTerms/06-Deep-Architectures-and-Generative-Models/03-Autoencoders_and_Latent_Spaces.md)

---

### Softmax Function
- **Spoken / Phonetic:** /ˈsɒft.mæks/ (SOFT-maks)
- **Formal Definition:** A normalized exponential map $\sigma: \mathbb{R}^K \to \Delta^{K-1}$ converting unnormalized real-valued logits $\mathbf{z}$ into a valid probability distribution: $\sigma(\mathbf{z})_i = \frac{e^{z_i}}{\sum_{j=1}^K e^{z_j}}$.
- **Intuitive Explanation:** Turning arbitrary network output numbers into clean percentage probabilities that sum to 100%.
- **Reference Term:** [06-Softmax.md](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/06-Softmax.md)

---

### Top-K Accuracy
- **Spoken / Phonetic:** /tɒp keɪ ˈæk.jʊ.rə.si/ (TOP KAY AK-yur-uh-see)
- **Formal Definition:** A categorical evaluation metric $\mathcal{M}_K = \frac{1}{N}\sum_{i=1}^N \mathbb{I}(y_i \in \mathcal{S}_K(\mathbf{x}_i))$, where $\mathcal{S}_K$ denotes the set of $K$ classes receiving the largest predicted posterior probabilities.
- **Intuitive Explanation:** Counting an answer as correct if the true category is included anywhere among the model's top $K$ guesses.
- **Reference Term:** [07-Argmax.md](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/07-Argmax.md)

---

### Global Average Pooling (GAP)
- **Spoken / Phonetic:** /ˈɡləʊ.bəl ˈæv.ər.ɪdʒ ˈpuː.lɪŋ/ (GLOH-bul AV-rij POO-ling)
- **Formal Definition:** A spatial pooling operator that computes the mean activation across all spatial coordinates for each channel: $\text{GAP}(\mathbf{X})_c = \frac{1}{H \cdot W}\sum_{i=1}^H \sum_{j=1}^W X_{c, i, j}$, reducing a tensor of shape $[B, C, H, W]$ to $[B, C]$.
- **Intuitive Explanation:** Condensing an entire feature map sheet into a single average number per channel without requiring learnable weights.
- **Reference Term:** [01-Convolution_and_Pooling.md](../../MathsTerms/06-Deep-Architectures-and-Generative-Models/01-Convolution_and_Pooling.md)

---

### Cross-Entropy Loss
- **Spoken / Phonetic:** /krɒs ˈɛn.trə.pi lɒs/ (KROSS EN-truh-pee LOSS)
- **Formal Definition:** The empirical risk objective for categorical distribution fitting: $\mathcal{L}_{\text{CE}}(\mathbf{y}, \hat{\mathbf{y}}) = -\sum_{k=1}^K y_k \log \hat{y}_k$, penalizing divergence between ground-truth labels and predicted class probabilities.
- **Intuitive Explanation:** A mathematical penalty score that heavily punishes the model when it is confident in the wrong answer.
- **Reference Term:** [08-Loss_Functions.md](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/08-Loss_Functions.md)

---

### Gradient Descent
- **Spoken / Phonetic:** /ˈɡreɪ.di.ənt dɪˈsɛnt/ (GRAY-dee-unt dih-SENT)
- **Formal Definition:** A first-order optimization algorithm that iteratively minimizes an objective function $f(\theta)$ by updating parameters in the direction of steepest local descent: $\theta_{t+1} = \theta_t - \eta \nabla f(\theta_t)$.
- **Intuitive Explanation:** Rolling a ball downhill along the steepest slope to find the lowest valley.
- **Reference Term:** [09-Gradient_Descent.md](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/09-Gradient_Descent.md)

---

### Tensor Shapes & Dimensions
- **Spoken / Phonetic:** /ˈtɛn.sər ʃeɪps/ (TEN-sor SHAYPS)
- **Formal Definition:** An ordered tuple of integers $(d_1, d_2, \dots, d_n)$ defining the extents of a tensor along each rank axis, such as $[B, C, H, W]$ for standard 4D mini-batch image tensors.
- **Intuitive Explanation:** The geometric dimensions (batch count, color channels, height, and width) defining how data is organized in computer memory.
- **Reference Term:** [04-Tensors_and_Shapes.md](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/04-Tensors_and_Shapes.md)
