# Mathematical Glossary — Lecture 48: Attention Part 1

This glossary provides exact spoken English pronunciations, formal mathematical definitions, operational systems roles, and disk-verified cross-references for core terminology introduced in Lecture 48.

| Term | Spoken English (Phonetic Syllables) | Concept Anchor | Formal Mathematical Definition | Operational Role in Deep Systems | Reference Dossier |
|:-----|:-----------------------------------|:---------------|:-------------------------------|:---------------------------------|:------------------|
| **Sequence Matrix ($X$)** | *SEE-kwens MAY-triks / EKS* | Token Sequence Embedding Tensor | $X = [x_1, \dots, x_T]^T \in \mathbb{R}^{T \times D}$ where each row $x_i \in \mathbb{R}^D$ | Serves as the primary 2D dense numerical representation of a sequence of $T$ tokens | [Tensors & Shapes](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/04-Tensors_and_Shapes.md) |
| **Query Matrix ($Q$)** | *KWEER-ee MAY-triks / KYOO* | Active Information Request Projection | $Q = X W^Q \in \mathbb{R}^{T \times D_Q}$, where $W^Q \in \mathbb{R}^{D \times D_Q}$ | Represents what each token seeks to discover or attend to from the contextual environment | [Vectors & Matrices](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/01-Vectors_and_Matrices.md) |
| **Key Matrix ($K$)** | *KEE MAY-triks / KAY* | Addressable Content Matching Tag | $K = X W^K \in \mathbb{R}^{T \times D_K}$, where $W^K \in \mathbb{R}^{D \times D_K}$ | Represents the addressable indexing signature of each token matched against incoming queries | [Vectors & Matrices](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/01-Vectors_and_Matrices.md) |
| **Value Matrix ($V$)** | *VAL-yoo MAY-triks / VEE* | Communicable Semantic Information | $V = X W^V \in \mathbb{R}^{T \times D_V}$, where $W^V \in \mathbb{R}^{D \times D_V}$ | Contains the actual feature payload that is extracted and aggregated once matching occurs | [Vectors & Matrices](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/01-Vectors_and_Matrices.md) |
| **Subspace Projection ($W$)** | *SUB-spays proh-JEK-shun / DOUBLE-yoo* | Learnable Coordinate Basis Transformation | Linear mapping $\mathcal{T}(x) = x W$ projecting vectors from $\mathbb{R}^D$ into $\mathbb{R}^{D_k}$ | Adapts and rotates coordinate axes via backpropagation to optimize task-specific representations | [Basis, Spans & Orthogonality](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/01b-Basis_Spans_and_Orthogonality.md) |
| **Latent Bottleneck ($H_T$)** | *LAY-tent BOT-ul-nek / AYCH SUB TEE* | Recurrent Information Squeeze | $H_T = \text{RNN}(x_T, H_{T-1}) \in \mathbb{R}^m$ acting as sole sequence representation | Limits long-range context by forcing all past information through a single fixed-size vector | [Recurrent Neural Networks](../../MathsTerms/06-Deep-Architectures-and-Generative-Models/02-Recurrent_Neural_Networks.md) |
| **Attention Weight ($\alpha_{t, i}$)** | *uh-TEN-shun WAYT / AL-fuh TEE EYE* | Simplex Alignment Coefficient | $\alpha_{t, i} = \frac{\exp(e_{t, i})}{\sum_{j=1}^T \exp(e_{t, j})} \in [0, 1]$ such that $\sum_{i=1}^T \alpha_{t, i} = 1$ | Governs the relative proportion of focus that output token $t$ assigns to input token $i$ | [Softmax](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/06-Softmax.md) |
| **Dynamic Context Vector ($c_t$)** | *dye-NAM-ik KAHN-tekst VEK-tor / SEE TEE* | Unattenuated Convex Combination | $c_t = \sum_{i=1}^T \alpha_{t, i} h_i \in \mathbb{R}^m$ | Bypasses recurrent bottlenecks by supplying the decoder with a customized blend of all encoder states | [Dot Product & Similarity](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/03-Dot_Product_and_Similarity.md) |
| **Inductive Bias** | *in-DUK-tiv BYE-us* | Hypothesis Space Architectural Prior | Mathematical assumptions $\mathcal{H}_{\text{arch}} \subset \mathcal{F}_{\text{all}}$ restricting model search space | Acts as structural regularization, controlling generalization error and sample complexity | [Activation Functions](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/05-Activation_Functions.md) |
| **Permutation Equivariance** | *per-myoo-TAY-shun ee-kwih-VAIR-ee-uns* | Order-Commutative Algebraic Invariance | Property $f(\Pi X) = \Pi f(X)$ for any permutation matrix $\Pi$ | Proves that token-wise linear projections preserve coordinate values regardless of token sequence order | [Vectors & Matrices](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/01-Vectors_and_Matrices.md) |
