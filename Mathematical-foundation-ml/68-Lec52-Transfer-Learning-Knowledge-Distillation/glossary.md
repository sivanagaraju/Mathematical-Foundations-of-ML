# Glossary of Core Terms: Lecture 52 (Transfer Learning & Knowledge Distillation)

A rigorous mathematical glossary defining the terminology, spoken phonetics, and operational definitions of Transfer Learning, Representation Tapping, Multitask Parameter Sharing, Temperature Scaling, and Knowledge Distillation.

---

## Terminology Dictionary

| Term | Spoken English (Phonetics) | Mathematical Symbol | Formal Mathematical Definition | Course / Conceptual Context | Foundation Link |
|:-----|:---------------------------|:--------------------|:-------------------------------|:----------------------------|:----------------|
| **Transfer Learning** | *TRANS-fer LERN-ing* | $\mathcal{D}_S \to \mathcal{D}_T$ | Reusing knowledge/parameters $\theta^*$ learned on source task $\mathcal{T}_S$ to optimize performance on target task $\mathcal{T}_T$. | Foundational paradigm avoiding training from scratch by transferring inductive biases across domains. | [01-Vectors_and_Matrices.md](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/01-Vectors_and_Matrices.md) |
| **Intermediate Embedding** | *in-ter-MEE-dee-ut em-BED-ing* | $Z = G^*_L(X) \in \mathbb{R}^D$ | Output activation vector tapped from layer $L$ of a pre-trained composite network $G^*(X)$. | Dense vector representation capturing invariant semantic features for downstream classifiers. | [04-Tensors_and_Shapes.md](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/04-Tensors_and_Shapes.md) |
| **Linear Probing** | *LIN-ee-er PROH-bing* | $\min_{\theta_h} \mathcal{L}(W_h Z + b_h, y)$ | Training only a linear classification head on top of frozen pre-trained representation features $Z$. | Fast, convex surrogate evaluation preventing catastrophic overfitting on small target datasets. | [08-Loss_Functions.md](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/08-Loss_Functions.md) |
| **Parameter Freezing** | *puh-RAM-uh-ter FREE-zing* | $\frac{\partial \mathcal{L}}{\partial \theta_{\text{trunk}}} \triangleq 0$ | Deactivating gradient computation (`requires_grad = False`) for a subgraph during backpropagation. | Inductive regularization locking backbone weights to pre-trained values and eliminating backward FLOPs. | [04-Chain_Rule_and_Backpropagation.md](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/04-Chain_Rule_and_Backpropagation.md) |
| **Multitask Hard Sharing** | *MUL-tee-task HARD SHAIR-ing* | $\nabla_Z \mathcal{L} = \sum_{k} \nabla_Z \mathcal{L}_k$ | Architecture sharing a single feature trunk across multiple distinct task heads with additive gradient backprop. | Enforces invariant representations across task manifolds, acting as a strong regularizer. | [09-Gradient_Descent.md](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/09-Gradient_Descent.md) |
| **Marginal Data Density** | *MAR-jin-ul DAY-tuh DEN-sih-tee* | $P(X) = \int P(X, Y) dY$ | Unconditional probability distribution over the input feature manifold. | Objective optimized by unsupervised and self-supervised models to learn universal feature representations. | [03-Joint_Marginal_Conditional_Dist.md](../../MathsTerms/03-Probability-and-Statistical-Estimation/03-Joint_Marginal_Conditional_Dist.md) |
| **Knowledge Distillation** | *NAH-lij dis-tuh-LAY-shun* | $G^*_{\text{teacher}} \to f_{\theta}^{\text{student}}$ | Transferring predictive capacity and representations from an overparameterized teacher to a compact student. | Core model compression framework enabling deployment of large foundation models onto edge hardware. | [02-KL_Divergence.md](../../MathsTerms/04-Information-Theory-and-Divergences/02-KL_Divergence.md) |
| **Dark Knowledge** | *DARK NAH-lij* | $\frac{p_i^\tau}{p_k^\tau} = e^{\frac{z_i - z_k}{\tau}}$ | Information encoded in the non-target soft probability distribution over incorrect classes. | Captures rich inter-class similarity metrics invisible in binary hard ground-truth labels. | [01-Entropy_CrossEntropy_CCE.md](../../MathsTerms/04-Information-Theory-and-Divergences/01-Entropy_CrossEntropy_CCE.md) |
| **Temperature Scaling** | *TEM-pruh-cher SKAY-ling* | $p_i^\tau = \frac{\exp(z_i/\tau)}{\sum_j \exp(z_j/\tau)}$ | Dilation of logit dynamics by positive scalar $\tau > 1$ to soften softmax probability distributions. | Reveals subtle dark knowledge logits and prevents extreme probability polarization during distillation. | [06-Softmax.md](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/06-Softmax.md) |
| **Fréchet Inception Distance** | *FRAY-shay in-SEP-shun DIS-tuns* | $\|\mu_r - \mu_g\|^2 + \operatorname{Tr}(\Sigma_r + \Sigma_g - 2(\Sigma_r \Sigma_g)^{1/2})$ | Metric measuring Wasserstein-2 distance between Gaussian-fitted feature representations from Inception layer. | Canonical example of empirical intermediate layer selection hyperparameter in transfer learning. | [10-Frechet_Inception_Distance.md](../../MathsTerms/06-Deep-Architectures-and-Generative-Models/10-Frechet_Inception_Distance.md) |
