## 6-Column Mathematical Dictionary

| Term | Formal Definition | Spoken English (Phonetics) | Intuition | Code / Computational Representation | MathsTerms Cross-Link |
|:-----|:------------------|:---------------------------|:----------|:------------------------------------|:----------------------|
| **Local Receptive Field** | The localized spatial subset $\mathcal{RF}(j) = \{j \cdot s, \dots, j \cdot s + k - 1\}$ of input dimensions directly connected to neuron $j$. | "LOH-kul ree-SEP-tiv feeld" | The tiny window of neighboring pixels that a single neuron inspects. | `x[j*s : j*s + k]` | [`01-Convolution_and_Pooling.md`](../../MathsTerms/06-Deep-Architectures-and-Generative-Models/01-Convolution_and_Pooling.md) |
| **Parameter Sharing** | An architectural constraint enforcing $W_{j, j \cdot s + r} = w_r$ for all spatial locations $j$, tying weights across space. | "puh-RAM-uh-ter SHAIR-ing" | Using the exact same feature-detecting template across every part of an image. | `nn.Parameter(torch.randn(k))` | [`01-Vectors_and_Matrices.md`](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/01-Vectors_and_Matrices.md) |
| **Translation Equivariance** | Property where shifting input by vector $v$ shifts the output by an identical displacement: $f(T_v x) = T_v f(x)$. | "trans-LAY-shun ee-kwih-VAIR-ee-uns" | If a cat walks to the right in the photo, the cat feature map moves to the right by the same amount. | `conv(torch.roll(x, 1)) == torch.roll(conv(x), 1)` | [`01-Convolution_and_Pooling.md`](../../MathsTerms/06-Deep-Architectures-and-Generative-Models/01-Convolution_and_Pooling.md) |
| **Translation Invariance** | Property where shifting input leaves output completely unchanged: $g(T_v x) = g(x)$. | "trans-LAY-shun in-VAIR-ee-uns" | Recognizing that a photo contains a cat, regardless of where the cat sits in the frame. | `pool(conv(torch.roll(x, 1))) == pool(conv(x))` | [`01-Convolution_and_Pooling.md`](../../MathsTerms/06-Deep-Architectures-and-Generative-Models/01-Convolution_and_Pooling.md) |
| **Grid Topology** | Coordinate structure $G \subset \mathbb{Z}^D$ where geometric Euclidean distance $\Vert u - v \Vert$ reflects statistical mutual information. | "GRID tuh-POL-uh-jee" | Data arranged in regular pixel rows/columns where adjacent neighbors are physically related. | `tensor.view(B, C, H, W)` | [`04-Tensors_and_Shapes.md`](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/04-Tensors_and_Shapes.md) |
| **Dirac Delta Prior** | Generalized singular probability distribution $\delta_0(w)$ concentrating infinite density at zero, enforcing $w \equiv 0$ with probability 1. | "DEER-ack DEL-tuh PRY-er" | Permanently cutting a neural connection by locking its weight to zero forever. | `mask = (W != 0)` | [`04-Likelihood_and_Log_Likelihood.md`](../../MathsTerms/03-Probability-and-Statistical-Estimation/04-Likelihood_and_Log_Likelihood.md) |
| **Banded Toeplitz Matrix** | A matrix with constant diagonals ($A_{i, j} = a_{i-j}$) whose non-zero entries are restricted to a narrow diagonal band. | "BAN-ded TEP-lits MAY-triks" | A linear transformation matrix that performs discrete convolution via sliding window multiplications. | `scipy.linalg.toeplitz` | [`01-Vectors_and_Matrices.md`](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/01-Vectors_and_Matrices.md) |
| **Discrete Cross-Correlation** | Sliding inner product $(w \star x)_j = \sum_{r=0}^{k-1} w_r x_{j \cdot s + r} + b$ between kernel template $w$ and input $x$. | "diss-KREET CROSS kor-uh-LAY-shun" | Testing how well a filter template matches each local patch of an input signal. | `torch.nn.functional.conv1d` | [`01-Convolution_and_Pooling.md`](../../MathsTerms/06-Deep-Architectures-and-Generative-Models/01-Convolution_and_Pooling.md) |
| **Effective Receptive Field** | The total spatial span in layer 0 that influences the activation of a single neuron in layer $L$: $RF_L = 1 + \sum_{l=1}^L (k_l - 1) S_{l-1}$. | "ee-FEK-tiv ree-SEP-tiv feeld" | The total field of view on the original image that a deep neuron sees through accumulated layers. | `rf_size = 1 + L * (k - 1)` | [`01-Convolution_and_Pooling.md`](../../MathsTerms/06-Deep-Architectures-and-Generative-Models/01-Convolution_and_Pooling.md) |
| **Ignorance Modeling** | Machine learning philosophy initializing free parameters randomly and letting empirical risk minimization learn representations from data. | "IG-ner-uns MOD-uh-ling" | Not pretending to know the best edge filter; letting gradient descent discover it automatically. | `nn.init.kaiming_normal_(conv.weight)` | [`09-Gradient_Descent.md`](../../MathsTerms/02-Multivariate-Calculus-and-Optimization/09-Gradient_Descent.md) |
