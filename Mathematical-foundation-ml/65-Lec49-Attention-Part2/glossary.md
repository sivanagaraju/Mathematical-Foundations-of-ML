# Glossary of Core Terms: Lecture 49 (Attention Part 2)

A rigorous mathematical glossary defining the notation, phonetics, and operational definitions of scaled dot-product attention and feedforward layers.

---

## Terminology Dictionary

| Term | Spoken English (Phonetics) | Mathematical Symbol | Formal Mathematical Definition | Course / Conceptual Context | Foundation Link |
|:-----|:---------------------------|:--------------------|:-------------------------------|:----------------------------|:----------------|
| **Scaled Dot-Product Attention** | *Skayld Dot PROD-ukt Uh-TEN-shun* | $\operatorname{Attention}(Q, K, V)$ | $\operatorname{softmax}\left(\frac{Q K^T}{\sqrt{D_k}}\right) V$ | The core linear routing engine of transformers computing pairwise sequence similarities normalized by root dimension. | [03-Dot_Product_and_Similarity.md](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/03-Dot_Product_and_Similarity.md) |
| **Query Matrix** | *KWEE-ree MAY-triks* | $Q \in \mathbb{R}^{T \times D_k}$ | $X W^Q$, where $W^Q \in \mathbb{R}^{D \times D_k}$ | Linear subspace projection representing what information each token actively seeks across the sequence. | [01-Vectors_and_Matrices.md](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/01-Vectors_and_Matrices.md) |
| **Key Matrix** | *KEE MAY-triks* | $K \in \mathbb{R}^{T \times D_k}$ | $X W^K$, where $W^K \in \mathbb{R}^{D \times D_k}$ | Linear subspace projection representing the searchable catalog labels or index tags advertised by each token. | [01-Vectors_and_Matrices.md](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/01-Vectors_and_Matrices.md) |
| **Value Matrix** | *VAL-yoo MAY-triks* | $V \in \mathbb{R}^{T \times D_v}$ | $X W^V$, where $W^V \in \mathbb{R}^{D \times D_v}$ | Linear subspace projection representing the actual semantic content or features communicated during aggregation. | [01-Vectors_and_Matrices.md](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/01-Vectors_and_Matrices.md) |
| **Variance Scaling Factor** | *VAIR-ee-uns SKAY-ling FAK-tur* | $\frac{1}{\sqrt{D_k}}$ | Scalar multiplier where $D_k$ is key feature dimension | Normalizes dot-product variance from $D_k$ back to $1.0$, preventing softmax gradient saturation and vanishing. | [01-Random_Variables_and_Distributions.md](../../MathsTerms/03-Probability-and-Statistical-Estimation/01-Random_Variables_and_Distributions.md) |
| **Row Probability Simplex** | *ROH prob-uh-BIL-ih-tee SIM-pleks* | $\Delta^{T-1}$ | $\{ a \in \mathbb{R}^T : \sum_{j=1}^T a_j = 1, \; a_j \ge 0 \}$ | Geometric subspace ensuring each row of the attention matrix forms a valid, non-negative probability distribution. | [01-Convexity_and_Jensens_Inequality.md](../../MathsTerms/05-Convexity-Duality-and-Metric-Analysis/01-Convexity_and_Jensens_Inequality.md) |
| **Convex Combination** | *KON-veks kom-bih-NAY-shun* | $z_i = \sum_{j=1}^T A_{i, j} v_j$ | $\sum_j \alpha_j v_j$ with $\alpha_j \ge 0, \sum_j \alpha_j = 1$ | Value aggregation property guaranteeing context vectors lie inside the bounding convex envelope of input values. | [01-Convexity_and_Jensens_Inequality.md](../../MathsTerms/05-Convexity-Duality-and-Metric-Analysis/01-Convexity_and_Jensens_Inequality.md) |
| **Permutation Equivariance** | *pur-myoo-TAY-shun ee-kwih-VAIR-ee-uns* | $f(P X) = P f(X)$ | Commutativity with permutation matrix $P \in \{0, 1\}^{T \times T}$ | Property stating that reordering input sequence tokens produces an identically reordered output sequence. | [01-Vectors_and_Matrices.md](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/01-Vectors_and_Matrices.md) |
| **Softmax Saturation** | *SAWFT-maks sach-er-AY-shun* | $\lim_{\|s\| \to \infty} \nabla_s \operatorname{softmax}(s) = 0$ | Extreme logit values producing one-hot vectors and vanishing derivatives | Failure mode occurring when unscaled logits cause exponential explosion, halting gradient backpropagation. | [02-Vector_Norms_and_Inner_Products.md](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/02-Vector_Norms_and_Inner_Products.md) |
| **Position-wise Feedforward Network** | *poh-ZISH-un-wyz FEED-for-wurd NET-wurk* | $\operatorname{FFN}(z)$ | $W_2 \sigma(W_1 z + b_1) + b_2$ | Intra-token two-layer MLP providing non-linear coordinate distortions for universal function approximation. | [04-Tensors_and_Shapes.md](../../MathsTerms/01-Linear-Algebra-Geometry-and-Tensors/04-Tensors_and_Shapes.md) |
